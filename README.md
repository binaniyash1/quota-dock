# Quota Dock

Floating desktop widget for AI usage across Cursor, Claude, ChatGPT, and Grok.

## Install

Download the latest release for your OS from GitHub Releases.

- Mac: `.dmg`
- Windows: `.exe`
- Linux: `.AppImage`

## Usage

1. Open Quota Dock
2. Click **Auto-detect logins**
3. Drag the widget anywhere on your screen

No terminal. No npm. No localhost.
